Project Methodology

This page explains the workflow used to build the dashboard and website.

1. Data Collection

Job market data was collected and organized for analysis.

2. Data Cleaning

Python and Pandas were used to clean missing values, remove duplicates, and prepare the dataset.

3. Dashboard Creation

Power BI was used to create interactive visualizations, KPIs, charts, and filters.

4. Website Development

HTML, CSS, and JavaScript were used to build a colorful multi-page portfolio website.
