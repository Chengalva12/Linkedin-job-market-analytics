About This Project

Interactive Job Market Analytics Dashboard using Power BI and Web Technologies

Project Overview

The Job Market Analytics Dashboard is an interactive business intelligence and data visualization project developed using Power BI, Python, Pandas, HTML, CSS, and JavaScript.

This project analyzes job market trends, hiring patterns, technical skills demand, company recruitment activity, and location-based opportunities using real-world job posting datasets.

The dashboard provides valuable insights into top hiring roles, top companies, most demanded technical skills, and industry hiring trends through interactive charts, KPIs, maps, and visual analytics.

Python and Pandas were used for data cleaning and preprocessing, while Power BI was used to build interactive dashboards and visualizations. HTML, CSS, and JavaScript were used to develop a colorful multi-page analytics website.

Technologies Used

Power BI • Python • Pandas • HTML • CSS • JavaScript • Data Visualization • Business Intelligence
