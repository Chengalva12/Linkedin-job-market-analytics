# LinkedIn Job Market Analytics Dashboard Website

An interactive and responsive analytics website developed using Power BI, Python, Pandas, HTML, CSS, and JavaScript to analyze job market trends, hiring patterns, top skills, and company recruitment insights.

---

## Live Demo

🔗 https://linkedin-job-market-analytics.vercel.app

---

## Project Overview

The Job Market Analytics Dashboard Website is a business intelligence and data visualization project designed to provide meaningful insights into real-world job market data.

The project combines:
- Power BI dashboards
- Data cleaning using Python and Pandas
- Interactive web development
- Business intelligence visualizations

Users can explore:
- Top hiring roles
- Most demanded technical skills
- Hiring trends
- Company recruitment analysis
- Location-based opportunities
- Interactive KPI dashboards
